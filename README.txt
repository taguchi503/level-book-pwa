森建設工業DX 水準測量・野帳アプリ v0.1.0 試作版

【主な機能】
- 現場入力画面と野帳画面を分離
- 「測定」「確認・履歴」「野帳」の3画面構成
- 現在の器械点、HI、次の測定種別を常時表示
- 点名＋読み値を大きく入力し、1ボタンで記録
- BS / FS / TPの大型ボタン
- TPはFSとして記録し、点名がTPで始まる場合に転点判定
- TP記録後は自動的に次BS待ちへ切替
- 直前の記録、最新5件、ΣBS・ΣFS・標高差を確認
- 「1つ戻す」「修正」
- 野帳一覧の行をタップして修正可能
- PDF・印刷、Excel（.xls）出力、共有
- 音声で「No.12 1.325」「TP1 1.455」「BS 1.325」等を入力可能

【データ互換・保護】
- 保存キー moriken_level_book_v0_1 は旧試作版から変更していません。
- 旧試作データの siteName / surveyDate / startPoint / startElev / initialBS / rows(point, fs, nextBS) を読み込みます。
- 旧データにない備考 note は空欄として補完します。
- 保存前に直前データをバックアップし、ミラー保存も行います。
- localStorage.clear() は使用しません。

【注意】
- 試作版です。不具合は実使用で確認しながら改善してください。
- 測量成果として使用する前に観測値・計算値を必ず確認してください。
- 音声認識はブラウザ・端末・騒音環境により精度が変わります。
